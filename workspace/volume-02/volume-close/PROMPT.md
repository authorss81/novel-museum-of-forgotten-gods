## THE STANDING RULES THIS MANUSCRIPT HAS LEARNED THE HARD WAY, AND WHICH THIS PHASE MUST NOT BREAK

1. **A day map in a phase prompt is not binding, and a week list in a state file is not binding either.** Derive every weekday from the pinned line and then write it down.
2. **A verification pass is a list of assertions, every one of which is grepped, and a sweep must report how many phrases it could not parse. That number has to be zero before its hit count means anything.** The last review's first sweep parsed **zero** phrases and would have reported no mismatches; the word-ordinal version parsed seventeen and found five. There is no number in this repository that has been certified by an assertion alone.
3. **A fact stated twice with different values is the most common defect in this manuscript, and the second statement is almost always the one that is wrong**, because it was written later and from memory.
4. **A claim that a repair was made is not the repair.** Check the file.
5. **A false figure promoted to a hard lock is how this manuscript loses a correction**, because every later pass is forbidden from looking. If you write a lock, check the figure from the pinned line first.
6. **A prompt that instructs a writer to break a correct record is worse than a prompt that is silent, and this manuscript is about exactly that.** One did, in Volume 02 Batch 0004, and it was caught only because a reviewer read the prompt as carefully as the prose.
