## THE STANDING RULES THIS MANUSCRIPT HAS LEARNED THE HARD WAY, AND WHICH THIS PHASE MUST NOT BREAK

1. **A day map in a phase prompt is not binding, and a week list in a state file is not binding either.** Derive every weekday from the pinned line and then write it down.
2. **A verification pass is a list of assertions, every one of which is grepped, and a sweep must report how many phrases it could not parse. 3. **A fact stated twice with different values is the most common defect in this manuscript, and the second statement is almost always the one that is wrong**, because it was written later and from memory. **A unit is not repaired until the state layer is repaired with the prose, and that has been the headline of two consecutive passes.**
4. **A claim that a repair was made is not the repair.** Check the file.
5. **A false figure promoted to a hard lock is how this manuscript loses a correction**, because every later pass is forbidden from looking. If you write a lock, check the figure from the pinned line first. ⚠ **Two figures are wrong in the Batch 0005 hand-off prompt this volume closed on — the bell's age, and the instruction about the term at the four flats — and both would have been promoted to locks by whoever read them next. 6. **A prompt that instructs a writer to break a correct record is worse than a prompt that is silent, and this manuscript is about exactly that.** One did, in Volume 02 Batch 0004. One nearly did in Volume 03 Batch 0005, in the other direction, by forbidding the mention of a live term that three batches had carried and a reader would otherwise think had been dropped. **Both errors are in this repository's prompt history and the audit should record them as a pair.**
7. **Nobody in this manuscript is a villain and everybody in this manuscript is competent, and the escalation rule is that each movement raises the number of people who can be hurt and not the size of anything.** Volume 03 ended on about nineteen hundred tenancies with no legal description and a case that can do its work without one man in it, and Volume 04 opens on a floor in a building, and the number it raises is staff.
